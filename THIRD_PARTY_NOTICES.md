## Spark Doctor

Spark AI Lab can optionally integrate with [Spark Doctor](https://github.com/joeynyc/spark-doctor), an independent NVIDIA DGX Spark diagnostic CLI created by Joey.

Spark Doctor is not bundled with this repository. Operators install it separately and explicitly enable the integration. Spark AI Lab detects the configured installation at runtime and hides its controls when the tool is unavailable.
